## 📌 Overview

This project explores global health and education indicators such as:

- 💰 GDP per capita
- 💉 Health expenditure (% of GDP)
- 📚 Literacy rate
- 👶 Life expectancy

It uses clean visualizations including:
- KPI Cards
- Line Charts
- Donut Charts
- Map Visuals
- Bar Charts

---


## 🛠️ Tools Used

| Tool      | Purpose                          |
|-----------|----------------------------------|
| Power BI  | Data visualization & dashboard   |
| Excel     | Data cleaning (initial)          |
| GitHub    | Project version control & sharing|

---

## 📂 Data Source

- Source: [World Bank Open Data](https://data.worldbank.org)
- Indicators used:
  - GDP per capita (current US$)
  - Current health expenditure (% of GDP)
  - Literacy rate, adult total (% of people ages 15 and above)
  - Life expectancy at birth, total (years)

---

## 🎨 Customizations & Styling

- Font: Segoe UI
- Rounded KPI cards with icons (💰, 💉, 📚, 👶)
- Dark theme background for contrast
- Data labels & tooltips enabled
- Clean layout using shapes and sections

---

## 🧠 Key Insights

- Countries with higher GDP tend to have better health and education outcomes.
- Life expectancy and literacy rate strongly correlate.
- Some low-GDP countries still maintain high literacy due to strong education policy.

---

## ✅ How to Use

1. Open `World_Health_Education.pbix` in Power BI Desktop
2. Refresh the dataset if required
3. Explore the dashboard tabs
4. Use filters to explore different indicators and years
